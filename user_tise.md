# Tise — User Workflow

## Overview
**Tise** is a privacy-first personal behavioral forecasting system.

> **Install → Choose Data Sources → Use Devices Normally → Tise Learns → View Predictions → Ask Why → Verify Outcomes → Improve**

## 1. Who Uses Tise?
Tise is designed for individuals who want to explore patterns in their own permitted digital activity.

Possible users:
- professionals
- students
- researchers
- productivity enthusiasts
- people interested in personal analytics

## 2. Install Tise

The initial product can include:

```text
Tise Browser Extension
        +
Tise Local Desktop Agent
        +
Tise Dashboard
```

```text
┌─────────────────────────────────────┐
│              TISE                   │
│   Your Personal Behavioral          │
│   Forecasting System                │
│                                     │
│         [ Get Started ]             │
└─────────────────────────────────────┘
```

## 3. Choose Data Sources

```text
What should Tise analyze?

☑ Browser activity
☐ Calendar
☐ Shopping imports
☐ Music activity
☐ Other approved integrations

[ Continue ]
```

For V1, the recommended starting point is:

> **Browser activity only**

## 4. Review Permissions

Example:

```text
Tise may analyze:

✓ Approved browsing events
✓ Time patterns
✓ Topic/category signals

Tise should avoid collecting:

✗ Passwords
✗ Authentication secrets
✗ Payment credentials
✗ Sensitive form data
```

The user should be able to:
- enable or disable sources
- pause collection
- delete data
- choose local-only processing

## 5. Use Devices Normally

After setup, the user simply uses connected services normally.

```text
Day 1
Search AI agents
Watch AI videos
Read AI articles

Day 2
Search AI frameworks
Visit repositories
Compare tools

Day 3
Read tutorials
Search implementation guides
```

In the background:

```text
Permitted Events
       ↓
Local Processing
       ↓
Behavioral Features
       ↓
Pattern Detection
       ↓
Prediction Models
```

Initially, Tise may show:

> **Still learning your patterns.**

## 6. Open the Dashboard

```text
┌─────────────────────────────────────────────┐

├─────────────────────────────────────────────┤
│ YOUR NEXT LIKELY ACTIONS                    │
│                                             │
```

The user sees:
- likely next actions
- probabilities
- expected time windows
- confidence/uncertainty

## 7. View a Prediction

```text
LIKELY NEXT ACTION

Continue AI research

Probability: 78%

Expected: Within 24 hours

Confidence: Medium-High

[ Why? ]
```

Predictions should be probabilistic, not guarantees.

## 8. Click “Why?”

```text
WHY DOES TISE THINK THIS?

• 12 AI-related searches in the last 3 days
• 6 AI-related pages visited
• Activity in this topic is increasing
• Similar historical sessions often continued
  into another research session
```

Statistical/ML models generate the prediction; the explanation layer presents the evidence clearly.

## 12. Verify Predictions

```text
Prediction Review

Tise predicted you would
revisit a research topic.

Did this happen?

[ Yes ] [ No ] [ Not Sure ]
```

Permitted event data can also confirm some outcomes automatically.

## 13. View the Prediction Scorecard

```text
YOUR TISE SCORECARD

Predictions evaluated: 42
Correct: 29
Accuracy: 69%

Confidence calibration:
Good

Best prediction category:
Research behavior
```

Additional evaluation can include precision, recall, Brier score, calibration, and forecasting error.

## 14. Ask Tise Questions

A conversational interface could support:

> What am I likely to do this evening?

> Why do you think that?

> What changed in my behavior this month?

> Which interests are becoming stronger?

The conversational layer should use structured predictions and evidence rather than inventing probabilities.

## 15. Control Privacy

```text
PRIVACY CONTROL

Browser Activity          ● ON
Application Activity      ○ OFF
Cloud Sync                ○ OFF
Local Processing          ● ON

Raw Data Retention        30 Days

Delete All Data           [ DELETE ]
```

The user controls:
- data sources
- processing location
- retention
- synchronization
- deletion

## 16. Simplified User Journey

```text
1. Install Tise
2. Choose data sources
3. Approve permissions
4. Use devices normally
5. Tise learns patterns
6. Open dashboard
7. View predictions
8. Ask “Why?”
9. Verify outcomes
10. Tise evaluates performance
11. Models improve over time
```

## 17. Recommended V1

### Installation
```text
Browser Extension + Local Tise Application
```

### Data source
```text
Browser activity only
```

### Main screens
- **Home:** What will I likely do next?
- **Predictions:** probability, time window, and why
- **Behavior:** emerging interests and trends
- **Privacy:** sources, retention, and deletion

After several days of normal browsing, the user opens Tise:

```text

🧠 Continue AI research
78% likely within 24 hours

💻 Visit programming resources
65% likely within 2 days

🔎 Compare AI development tools
57% likely within 3 days
```

Clicking a prediction shows evidence:

```text
WHY?

• 14 related searches
• 8 technical articles
• 5 tool comparisons

Activity increased compared with
the previous week.
```

Over time, Tise transparently reports measured performance.

## Final Summary

> **A user installs Tise, explicitly chooses which data sources to connect, uses their devices normally, and later returns to a privacy-controlled dashboard that shows behavioral trends, emerging interests, probabilistic predictions, explanations, and evidence about how well those predictions performed.**
